# 눈치백단타이머 (Nunchi 100)

> *Nunchi level: 100. Interruptions: 0.*

PC를 켜면 작업/휴식 사이클과 일정을 **한국어 음성**으로 알려 주는 Windows용 데스크톱 앱입니다.
게임 중에는 조용히 기다렸다가 끝나면 알려 주고, 말할 때는 유튜브 소리를 살짝 줄이는 **눈치 백단** 타이머예요.
작업 표시줄 트레이에서 조용히 실행되고, 다크 테마 창에서 알람·캘린더·음성을 관리합니다.

> **nunchi(눈치)**: 분위기를 읽고 알맞게 행동하는 감각. 2021년 옥스퍼드 영어사전에 실린 한국어 단어예요.

## 주요 기능

- **메인 알람**: 60분 작업 → 10분 휴식을 반복하며 음성으로 알림 (시간·문구 변경 가능), 원형 타이머, 오늘 작업/휴식 횟수
  - 프로그램만 다시 켜면 타이머가 이어지고, PC를 끄거나 절전했다가 켜면 새로 시작
- **특정 시각 알람**: 한 번만 / 매일 / 평일 / 요일 선택 반복
- **캘린더**
  - 월간 달력, 한국 공휴일(대체공휴일 포함)과 음력 표시
  - 하루 일정, 여러 날에 걸친 기간 일정(막대 표시), 반복 일정(매주, 매월 N번째 요일, 매월 마지막 요일, 매년 등)
  - 일정마다 알림 시점·간격을 직접 설정 (예: 2시간 전부터 30분마다, 10분 전 한 번만)
  - PC를 켤 때 오늘 일정 음성 브리핑
- **음성**: 기본 한국어 음성(오프라인) 또는 Microsoft 온라인 음성 선택, 볼륨·빠르기 조절
- **다른 소리 줄이기**: 알림이 나오는 동안 유튜브·방송 같은 다른 프로그램 소리를 잠깐 줄였다가 되돌림
- **게임 모드**: 등록한 게임이 실행 중이면 알림을 모아 두었다가 게임이 끝나면 한꺼번에 알림
- **사용 기록**: PC를 켜고 끈 시각을 날짜별로 기록 (1년 보관, 지난 기록은 정리 여부를 물어봄, txt 내보내기)
- **설정**: PC 켜면 자동으로 실행 켜기/끄기

## 필요 환경

- Windows 10 / 11
- [Python 3.10 이상](https://www.python.org/downloads/) — 설치할 때 **"Add python.exe to PATH"** 체크
- 한국어 음성: Windows 설정 → 시간 및 언어 → 음성에서 한국어 음성이 있으면 사용합니다. 없으면 온라인 음성을 고르세요.

## 설치와 실행

1. 이 저장소를 내려받습니다. (초록색 **Code** 버튼 → **Download ZIP** 후 압축 풀기, 또는 `git clone`)
2. 폴더 안의 **`install.bat`** 을 더블클릭합니다. 필요한 패키지를 설치하고 프로그램을 실행합니다.
3. 처음 실행하면 창이 열립니다. 이후에는 작업 표시줄 오른쪽 **트레이 아이콘을 더블클릭**하면 창이 열립니다.
4. PC를 켤 때 자동으로 실행하려면 창의 **[설정] → PC 켜면 자동으로 실행**을 켭니다.

다음부터는 **`run.bat`** 을 더블클릭하거나 `time_alarm.pyw` 를 실행하면 됩니다.

창의 X 버튼은 창만 숨깁니다. 완전히 끄려면 트레이 아이콘을 우클릭 → **종료** 를 누르세요.

## 데이터

처음 실행하면 프로그램 폴더에 아래 파일이 만들어집니다. 이 파일들은 저장소에 올라가지 않습니다.

| 파일 | 내용 |
|---|---|
| `alarms.json` | 메인 알람·특정 시각 알람·캘린더 일정·음성·게임 목록 설정 |
| `records.json` | PC 사용 기록 |
| `state.json` | 메인 알람 진행 상태 (프로그램만 다시 켰을 때 타이머를 이어가기 위함) |
| `기록 백업/` | 사용 기록을 txt로 내보낸 파일 (기본 저장 위치) |

설정을 처음 상태로 되돌리려면 프로그램을 종료하고 `alarms.json` 을 지운 뒤 다시 실행하세요.

## 알아 두실 점

- **온라인 목소리**(선희·인준·현수)를 고르면 알림 문구가 음성 생성을 위해 Microsoft 온라인 음성 서비스로 전송됩니다. 인터넷이 끊기면 기본 음성으로 대신 읽습니다.
- 공휴일은 [holidays](https://pypi.org/project/holidays/) 라이브러리, 음력은 [korean-lunar-calendar](https://pypi.org/project/korean-lunar-calendar/)(한국천문연구원 기준)를 사용합니다. 새로 지정된 임시공휴일은 라이브러리를 업데이트해야 반영됩니다.
  ```
  python -m pip install --upgrade holidays
  ```
